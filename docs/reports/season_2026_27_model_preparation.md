# 2026-2027シーズン開始時 改善・改修記録

ステータス: レビュー待ち
コード確定コミット: `734ff0e` (`Prepare leakage-safe 2026-27 prediction model`)

## 1. 目的と対象範囲

2026年のJ1百年構想リーグ（以下 `2026_special`）終了後、2026-2027年の通常J1開幕に向けて、試合前に利用できる情報だけで学習・推論するモデルへ改修した。

今回の対象は、学習データの再構築、データリーク防止、特別リーグを含む再学習、評価、モデル反映、予測出力とUIの大会固定表記の解消である。新シーズンの日程取得とルヴァンカップ対応は、依頼により今回の対象外とした。

## 2. 採用した運用方針

- `2021-2025` の通常J1と `2026_special` を結合したモデルを本番モデルとして使用する。
- 通常J1だけで学習したモデルをシャドーモデルとして保持し、新シーズン中に同じ試合を並行予測する。
- 公開予測は本番モデルだけで生成し、シャドー予測は別ファイルへ保存する。
- 新シーズン中は毎節、予測時点の特徴量スナップショットを保存する。
- 一定試合数が蓄積した時点で本番モデルとシャドーモデルを比較し、通常年モデルへの切替や再学習を判断する。

この方針は、特別リーグの追加が単独の勝敗分類精度を改善しなかった一方、スコア補正後の最終勝敗精度と完全一致率を改善したため採用した。特別リーグは通常年と大会構造が異なるため、無条件に有効とみなさず、シャドーモデルで継続監視する。

## 3. 特徴量の時点ルール

| 特徴量 | 採用ルール | 理由・出所 |
| --- | --- | --- |
| `Attendance` | 学習・推論から除外 | 実績観客数は試合後に確定するためリーク |
| `Stadium_Fill_Rate` | 学習・推論から除外 | 実績観客数から導くためリーク |
| Weather系列 | 学習・推論から除外 | 現行運用方針を維持 |
| `*_Rank_Delta_3` | 試合前の最新順位から、4つ前に保存した順位を引く | 第N試合では「N-1時点 − N-4時点」に相当 |
| `*_Urgency_Score` | 当該試合前の順位・勝点から再計算 | 当該試合結果を使用しない |
| Rolling xG | Football Labの公開値を試合平均のまま使用 | 既に1試合当たりの値であり節数で割らない |
| AGI / KAGI | Football Labの公開指数をそのまま使用 | 指数であり節数で割らない |
| フォーメーション | 当季の過去試合での最頻値。同数時は直近を優先 | 開幕時は前年最頻値、取得不能時は `4-4-2` |
| 順位・勝点・Elo・直近成績・休養日 | 日付順に試合前状態を再構築 | 同日試合は全行確定後に一括更新 |

過去に節別スナップショットがない xG / AGI / KAGI は、取得可能なシーズン集計値を推定値として割り当てる。これは実測の試合前スナップショットとは区別し、特徴量ごとの出所CSVに記録する。

## 4. 学習データの再構築

### 4.1 通常J1（2021-2025）

- 1,752試合を再構築した。
- 実績観客数と収容率を全行で除外した。
- 順位、Rank Delta、勝点、Elo、直近5試合勝点、緊急度、休養日を試合前状態から再計算した。
- フォーメーションを当季の過去試合の最頻値へ置き換えた。
- 旧データで38分割されていた xG / AGI / KAGI を、Football Labの公開単位へ復元した。

### 4.2 2026特別リーグ

- 終了済み200試合を学習対象とした。
- キックオフより前に保存された有効なスナップショットは21試合だった。
- 残る179試合は、動的特徴量を試合前状態から再構築し、xG / AGI / KAGI等は集計推定値を割り当てた。
- EAST / WESTグループ戦の緊急度はグループ首位との勝点差から算出した。
- 共通の順位境界を定義できないプレーオフの緊急度は0とした。

## 5. 評価結果

### 5.1 通常年モデル

2021-2024年を学習、2025年380試合を評価した。

| 指標 | 結果 |
| --- | ---: |
| 勝敗分類精度 | 40.5% |
| 最終勝敗精度 | 41.6% |
| 最終スコア完全一致 | 14.2% |
| 平均得点MAE | 0.875 |

### 5.2 特別リーグ後半の共通ホールドアウト

2026年5月1日以降の71試合を評価対象とし、特別リーグを使う場合はそれ以前の129試合だけを学習へ追加した。

| 学習条件 | 勝敗分類 | 最終勝敗 | 完全一致 | 平均得点MAE |
| --- | ---: | ---: | ---: | ---: |
| 通常年のみ | 43.7% | 42.3% | 14.1% | 0.930 |
| 特別リーグ前半追加・外部値は履歴prior | 38.0% | 36.6% | 16.9% | 0.957 |
| 特別リーグ前半追加・集計推定使用 | 38.0% | 43.7% | 18.3% | 0.948 |

本番採用モデルは3行目である。勝敗分類器単独は通常年モデルを下回るが、アプリが表示するスコア補正後の最終勝敗と完全一致率は上回った。評価対象が71試合と小さいため、この差を恒久的な優位とはみなさない。

## 10. 新シーズン開始後に確認する事項

- 毎節の予測前スナップショットが保存されていること。
- xG / AGI / KAGIの取得時刻がキックオフ前であること。
- 本番モデルとシャドーモデルについて、勝敗精度、完全一致率、MAE、確率校正を同一試合集合で比較すること。
- 特別リーグ特有の地域分割・試合数・大会目的による分布差が、新シーズンでも悪影響を与えていないこと。
- 日程取得を実装する際に `ACTIVE_COMPETITION_KEY` と入力ファイルを `2026_27_j1` へ切り替えること。
